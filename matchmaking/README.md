# Генератор UFC-кардов

Python 3.10+, без внешних зависимостей.

Запуск из /workspace/output:

    python matchmaking.py roster.example.json --event ppv --seed 42 > card.json
    python matchmaking.py roster.example.json --event fight_night --seed 42 > card.json

roster.example.json и card.*.example.json содержат ВЫМЫШЛЕННЫЕ демонстрационные данные, не ростер из Telegram.
Для работы замените fighters реальными данными. Каждая запись содержит id, name, division,
rank (1..15 либо null), champion, wins, losses, active, available.
История: history = [[fighter_a_id, fighter_b_id], ...]. ID могут относиться к бывшим бойцам.
history_complete=true является явным подтверждением полноты загруженной истории.
Не ставьте true, если история неизвестна: генератор не проверяет полноту внешнего источника.

Правила: 13 боёв и 26 уникальных бойцов, одна категория на пару, без прошлых встреч.
Fight Night исключает чемпионов и требует хотя бы одну пару топ-5.
PPV требует титульный бой чемпиона с №1 или №2; допускает несколько титульных боёв.
Рейтинговые: разница максимум 2. Нерейтинговые: разница побед и поражений максимум 2,
разница общего числа боёв максимум 3. Смешанные пары запрещены.
Структура: Main Event, Co-Main Event, 4 дополнительных Main Card, 7 Prelims.

Алгоритм строит граф допустимых пар и ищет сочетание 13 непересекающихся рёбер с
обязательным главным/титульным боем. Поиск возвращает первый допустимый кард с
приоритетом близких соперников; глобальный оптимум качества не гарантируется.
Иерархия: титульные, рейтинговые (сумма мест, затем разрыв), нерейтинговые
(сумма побед, затем близость рекордов). Случайность разрешает равенства.
Одинаковые данные и seed воспроизводят результат; новый seed не гарантирует иной кард.
По умолчанию поиск ограничен 10 секундами, меняется через --timeout.
Таймаут отличается от доказанного отсутствия решения. Неполный кард не выдаётся.

Telegram не подключён автоматически. Публичные сообщения требуют нормализации имён,
проверки актуальности категорий, чемпионов и дополнения историей встреч.

Проверено: 40 сценариев генерации, уникальность бойцов, оба типа турниров,
запрет реваншей, воспроизводимость и 5 случаев некорректных/недостаточных данных.
